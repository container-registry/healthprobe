# Support

## Questions

Ask in an issue, using the
[question form](https://github.com/container-registry/healthprobe/issues/new?template=question.yml). There is one
inbox on purpose, so nothing sits unanswered in a second one.

## Bugs and Feature Requests

Search [existing issues](https://github.com/container-registry/healthprobe/issues) first, then file a
[bug report](https://github.com/container-registry/healthprobe/issues/new?template=bug_report.yml) or a
[feature request](https://github.com/container-registry/healthprobe/issues/new?template=feature_request.yml).
The forms ask for what a useful report needs.

## Security Issues

**Never in a public issue.** Report privately via
[a security advisory](https://github.com/container-registry/healthprobe/security/advisories/new); see
[SECURITY.md](SECURITY.md).
